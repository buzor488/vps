## 二、"会不会跑路？"——关于野草云的几个常见疑问

### 1. 公司背景与资质：是个皮包公司吗？

野草云背后是 Lucida Cloud Limited（HK），香港公司编号 2736053，可以在香港公司注册处查到。同时它是 APNIC 和 RIPE NCC 会员，意味着它持有自己的 IP 段和 ASN 资源，不是租用别人的 IP 临时倒卖。

这点很重要：自己持有 IP 资源的商家，跑路成本远高于"借 IP 倒卖"的二道贩子，因为 IP 资源本身有价值，跑了等于扔钱。

### 2. 客服响应速度怎么样？

这是野草云被吐槽比较多的一个点。根据多篇用户实测反馈，客服响应速度属于"一般"水平，工作时间大致是 10:00–24:00，工单通常几小时内回复，但高峰时段偶尔会慢一些。不算惊艳，但也不至于失联。

### 3. 退款政策友好吗？

野草云的 VPS 系列支持**自购买日起 3 天内退款**，前提是没有滥用或违反服务条款。对于独立服务器，工作时间下单后 1–2 小时内完成系统安装交付。3 天的窗口不算长，但对于想跑一遍基准测试再决定要不要留的用户来说，够用。

### 4. 需要实名认证或 ICP 备案吗？

目前不强制要求实名认证，也不需要 ICP 备案。但官方明确写了：**不能通过 VPN 等匿名网络购买**，注册联络资料必须真实，一旦账户被判定有风险，需提供 HK ID / 身份证 / 护照 / 驾照等有效证件。这个政策其实比较"香港本地化"，对国内用户来说门槛不算高。

### 5. IPv4 是原生香港 IP 吗？

不一定是。官方明确说明：因为全球 IPv4 紧缺，分配的可能是 APNIC、RIPE、AFRINIC 等区域的 IPv4，**随机分配，不承诺切换**，但都宣告到香港、地理位置也更新为香港，速度上没有区别。

如果你对"原生香港 IP"有强需求（比如做某些对 IP 归属地敏感的业务），这点要在下单前心里有数。IP 不干净可以在购买后 24 小时内免费更换一次。

## 三、野草云的网络线路：优质 / 精品 / 国际 BGP 怎么选？

野草云香港机房接入了中国电信 CN2、中国联通、中国移动 CMI、NTT、Level3、HKIX、HE 等多家运营商，自建 BGP 网络。它把香港线路分成三种，命名有点像餐厅的"经典款 / 升级款 / 国际款"，区别主要在**回程路由**：

| 线路类型 | 电信回程 | 联通回程 | 移动回程 | 适合场景 |
| --- | --- | --- | --- | --- |
| 优质 BGP | CMI | CU / NTT / CMI 均衡 | Level3 | 国内综合访问、建站 |
| 精品 BGP | CU | CU | CMI | 对延迟敏感、电信方向优化 |
| 国际 BGP | 不含 CMI/CU，择优选路 | 同左 | 同左 | 面向东南亚、海外业务 |

需要特别留意官方那行小字："为提高攻击防护能力，优质 / 精品 BGP 所包含的 CMI、CU 中国内地路由仅承诺出口，入向无承诺。"翻译成人话就是：回程给你优化，但入向（从国内访问你服务器的方向）不保证一定走优化线路。日常建站感知不明显，但如果你做的是对入向延迟极敏感的业务（比如游戏加速），需要自己测一下再决定。

另外，野草云今年对所有香港 VPS 免费开放了**"云上互联 · 端口加速（CNIX）"**服务，可以和阿里云华南、腾讯云、UCloud 等主流云厂商高速互联，广深区域互联延迟低至 4–7ms，对 SSH、RDP、FTP 这类对延迟敏感的远程场景挺有用。
